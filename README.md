# Task Tracker — калькулятор функций

Выбор стартового набора и дополнительных функций с расчётом стоимости разработки.

Публичная страница: https://alexander-charnukho.github.io/task-tracker-calculator/

Четыре набора: $1 300, $2 400, $3 300 и «Всё самое необходимое» за $4 700. Дополнительные функции выбираются отдельно. Кнопка «Сбросить допопции» возвращает состав выбранного набора. Выбор сохраняется в браузере и передаваемой ссылке.

Цены предварительные; серверы, сопровождение и платные внешние сервисы оплачиваются отдельно.

Автономный HTML без внешних зависимостей. GitHub Pages публикуется из корня ветки main.
